# 卡提希娅表情包 · 动作与贴纸合辑

把散落在两个压缩包里的卡提希娅表情整理成 AstrBot 表情包管理器可直接使用的资源包：共 **425** 张 300×300 图片（**141** 个动态 GIF + **284** 张静态 PNG），按使用场景归为 **22** 个分类。

## 目录结构

```text
.
├── manifest.json          # 表情包清单（ID、版本、分类与描述）
├── memes/                 # 表情图片，按分类存放
│   ├── happy/
│   │   ├── happy_g032.gif
│   │   └── happy_p015.png
│   └── ...
├── previews/
│   └── cover.jpg          # 预览图 / 图标
├── MAPPING.csv            # 每个文件的分类与原始文件名对照
└── README.md
```

图片命名规则为 `<分类>_<g|p><三位序号>.<扩展名>`：`g` 表示来自 GIF 动作包，`p` 表示来自 PNG 贴纸包，原文件名见 [MAPPING.csv](MAPPING.csv)。

## 安装与使用

先安装并启用 **astrbot_plugin_meme_manager**（表情包管理器，v5.2.2 及以上）。

**方式一：本地压缩包导入（私有仓库用这个）**

1. 把仓库打包成 zip（包根目录就要有 `manifest.json` 和 `memes/`，不要多套一层文件夹）。
2. 插件 WebUI → **设置中心 → 导入与备份 → 导入表情包压缩文件**，选择这个 zip 导入。
3. 到 **设置中心 → 使用规则**，把本包设为默认，或绑定到指定会话 / 人格，然后保存规则。

**方式二：从 GitHub 安装（仅公开仓库）**

1. 资源广场 → **通过 GitHub 仓库地址安装** → 填 `kingoflove09/-meme`。
2. 插件下载压缩包时不带任何凭证，私有仓库会直接返回 404，所以只有把仓库设为公开后这条路才可用；插件本身也没有配置 GitHub Token 的入口。
