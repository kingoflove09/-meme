
## 安装与使用

1. 在 AstrBot 中安装并启用 **astrbot_plugin_meme_manager**（表情包管理器，v5.2.2 及以上）。
2. 打开插件 WebUI → **资源广场**，粘贴本仓库地址 `https://github.com/kingoflove09/-meme` 安装。
3. 安装后到 **设置中心 → 使用规则**，把本包设为默认，或绑定到指定会话 / 人格，然后保存规则。

> 本仓库是私有仓库。如果 WebUI 拉取失败，可以先把仓库克隆到本地，再复制进插件的 `data/plugin_data/meme_manager/packs/` 目录；或在安装时提供有 `Contents: Read` 权限的 GitHub Token。
